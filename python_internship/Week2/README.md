How to Use / Test

On running main.py, a menu appears:

===== Library Management System =====
1. Add Book
2. List Books
3. Update Book
4. Delete Book
5. Add Member
6. List Members
7. Update Member
8. Delete Member
9. Exit

Example 

Add Book

Input: Title: Python 101, Author: John Doe, ISBN: 12345

Output: Book 'Python 101' added successfully.

List Books

Output:

Books in Library:
Book -> Title: Python 101, Author: John Doe, ISBN: 12345


Update Book

Input ISBN to update, new title/author

Output: Book '12345' updated successfully.

Delete Book

Input ISBN

Output: Book '12345' deleted successfully.

Add Member

Input: Name: Alice, ID: M001

Output: Member 'Alice' added successfully.

List Members

Output:

Library Members:
Member -> Name: Alice, ID: M001


Update Member

Input Member ID, new name

Output: Member 'M001' updated successfully.

Delete Member

Input Member ID

Output: Member 'M001' deleted successfully.

Exit

Ends program.
